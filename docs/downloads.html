Downloads

Releases are published on GitHub. Each release includes linea and lineash for multiple platforms.

  • Releases → GitHub Source and pre-built binaries
  • Linux: amd64, 386, arm64 (.tar.gz)
  • Windows: amd64, 386, arm64 (.zip)
  • macOS: amd64, arm64 (.tar.gz)

Or build from source:

go build -o bin/linea
# Windows: go build -o bin/linea.exe

# Install: go install
