Linea

Commandline Workflow Tool

Define and run workflows in YAML. One file works on Windows, Linux, and macOS—version control your commands, override variables at runtime, and dry-run before you execute. No more platform-specific scripts.

CLI YAML cross-platform workflows variables dry-run
Get Linea See how it works
echo-variables.yml
# Echo command with variable substitution
command: echo
args:
  - "Message: {message}"
  - "User: {user}"
variables:
  message: "Welcome to Linea CLI"
  user: "Developer"

Linea organizes commands into workflows using YAML. Define and manage complex command-line tasks the same way on Windows, Linux, and macOS.
