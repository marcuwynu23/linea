Features

YAML-Driven Execution

Define commands, subcommands, and arguments in YAML. Version control, share, and document workflows easily.

Cross-Platform

Automatic OS detection, path separator conversion, and Windows shell built-in support. One YAML works everywhere.

Variable Substitution

Use {variable} or $variable with validation. Override at runtime with -s/--set.

Dry-Run Mode

Preview commands without executing: linea test workflow.yml. Safe testing and debugging.

Linea App

Create structured app dirs with linea app create my-app: workflows in .linea/workflows/ and Lineash scripts.

Lineash Scripts

Bash-like scripts (conditionals, loops, variables) that run Linea workflows as first-class commands.

Help & Init

linea help file.yml shows command info; linea init file.yml scaffolds a new workflow with docs.

Multiple Commands

Separate commands with --- in one file. Run sequences, build workflows, version control entire flows.
